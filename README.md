# 個人急難募資平台 網頁初版

純 HTML/CSS 的網頁初版，由 Claude 設計畫布轉成。直接用瀏覽器打開 `index.html` 即可預覽，不需要建置。

| 檔案 | 內容 |
|---|---|
| `index.html` | 首頁 |
| `register.html` | 註冊（可選捐款人／募資人，基本資料皆選填，可選匿名） |
| `login.html` | 登入（含 Google 登入按鈕，僅介面） |
| `my-donations.html` | 捐款人會員中心：捐款紀錄、個人資料 |
| `terms.html` | 使用者條款（草案，內容來自法律文件草案） |
| `privacy.html` | 隱私政策（草案） |
| `refund.html` | 退款說明（草案） |
| `campaigns.html` | 捐贈：所有進行中案件列表 |
| `campaign.html` | 案件頁（含手機版，響應式） |
| `donate.html` | 捐款頁 |
| `create-beneficiary.html` | 發起求助 步驟 1：類型與受益人 |
| `create-documents.html` | 發起求助 步驟 3：上傳文件 |
| `dashboard.html` | 發起人後台 |
| `styles.css` | 共用樣式與設計變數（顏色、字體、元件） |

## 目前的產品規則
- **會員系統：** 可註冊為捐款人或募資人，基本資料皆為選填。捐款人可以匿名；**募資人不能完全匿名**，一定要有顯示名稱，綽號或小名皆可，案件頁只顯示這個名稱。
- **一個帳號只能有一種身分**（捐款人或募資人），不能互轉；想兩者都做，須用不同的 Email 分別註冊。
- **登入方式：** Email＋密碼；Google 登入目前只有介面，尚未開發功能。
- **捐款不強制註冊**（訪客可直接捐款）；**發起求助一定要註冊**，可先註冊，或在「發起求助」步驟 1 建立案件時同步註冊。
- **只有受益人本人或其法定代理人可以發起**，不開放家人、親友代為發起。
- 案件**不需要先驗證身分**，通過文件審核即可上架。
- **提領前必須提供身分證明**，證明上的姓名須與匯款帳戶戶名一致；戶名須為受益人本人（受益人為未成年或無行為能力者時，為法定代理人）。
- 因為案件可能尚未驗證，案件卡片與案件頁會標示「身分已驗證／尚未身分驗證」。
